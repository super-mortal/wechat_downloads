把微信扫码绑定
搬到浏览器里

单次扫码即可把本机部署的 wechat-downloads 与你的微信连起来，用于自动接收公众号文章链接、归档并生成 HTML 页面。整个过程不依赖命令行终端。

使用步骤

  1. 点击下方 「开始扫码」 按钮，浏览器会调出 /admin/qr 页面。
  2. 页面会向 https://ilinkai.weixin.qq.com 申请一张二维码（5 秒内出图）。
  3. 打开手机微信 → 「扫一扫」→ 对准浏览器中的二维码。
  4. 手机端点击「登录 / 确认」，浏览器状态会从 等待扫码 自动切到 已确认。
  5. 确认后即可关掉这个标签页，回到首页继续使用。
开始扫码
说明：每次扫码会换一张新的二维码（旧的自动失效）。如果二维码在 5 分钟内无人扫描，会显示「二维码已过期，请刷新页面重新开始」。

路由速览

GET/admin   — 说明页（当前页） GET/admin/qr   — 二维码 + 状态轮询页 POST/admin/qr/start   — 申请一张新二维码，返回 { qrcodeUrl, sessionKey } GET/admin/qr/status?session=<key>   — 查询扫码状态，每 2 秒轮询
